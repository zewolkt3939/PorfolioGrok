Log channels

Default Windows channels you will open first during triage:

ChannelWhat it coversYour notes
Security Logon, account changes, process creation (if audit enabled)
System Service installs, driver issues, reboots
Application App-level errors / custom sources
PowerShell / Sysmon Script blocks, network, process tree (if deployed)

IDMeaningWhy it matters

Investigation workflow

  1. Scope — host, time window, user/IP from the alert.
  2. Timeline — pivot Event Viewer / SIEM around first bad signal.
  3. Process / logon chain — who ran what, from where.
  4. Persistence & egress — services, tasks, unusual network.
  5. Document — IOC list + recommended containment.
